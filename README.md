# AtmoSync – Micro-Climate Arbitrage Analytics

## About the Project
AtmoSync (Micro-Climate Arbitrage Analytics) is a data engineering and analytics project that processes agricultural market prices and container telemetry data.

The project uses Python, Apache Kafka, and Snowflake to ingest, store, and analyze data. SQL analytics identify price differences across agricultural markets to highlight potential arbitrage opportunities.

The agricultural dataset contains 12,672 processed price records.
## Project Objectives
- Understand the provided dataset
- Clean and preprocess data
- Perform data analysis
- Identify relevant patterns and opportunities
- Develop visualizations and a dashboard
